# mats-values

Working repo for the stated-utility / value-direction sprint project.

- `causes/inputs/` — the domain reference and the generation prompt given to the cause generator.
- `causes/codex/round1/`, `causes/codex/round2/` — the generator's raw output per round (`causes.jsonl`, `checks.md`), unchanged.
- `causes/reviewed/` — reviewed JSONL per round and the review digests.
- `causes/tools/` — checker, review brief, review assembler, seeded sampler.
